# Cloud Crypto Forecast (prototype)\n\nAdditive deployment in a separate folder; it does not overwrite the root dashboard. Uses public Binance spot hourly candles for BTC, ETH, XRP and SOL, nearest-historical-analogue scenarios for 4h/24h/72h, current-only derivatives readings, rolling JSON history and optional Telegram alerts.\n\n## Run it\nOpen Actions and run **Cloud Crypto Forecast** manually once. The dashboard path is `https://nakshatro.github.io/crypto-checkpoint/cloud-predictor/docs/` if GitHub Pages is configured to serve the repository root. If Pages is configured for `/docs`, the subfolder dashboard may not be served; adjust Pages to deploy from branch root or use the repo's existing site path. Scheduled runs are best-effort.\n\n## Telegram (optional)\nCreate a bot via @BotFather, then add repository Actions secrets `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID` under Settings → Secrets and variables → Actions. Never commit the token or share it in chat.\n\n## Limitations\nThis is an experimental baseline, not a validated prediction model. Up-frequency is historical analogue frequency, not a calibrated probability. Derivatives are current-only, initial data history is limited, and no out-of-sample profitability has been demonstrated. Data is committed to the repository; keep secrets out of the repo.\n
