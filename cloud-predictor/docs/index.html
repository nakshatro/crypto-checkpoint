5. How to read this dashboard

Bullish / bearish lean
A directional interpretation of the five-layer weighted model. It is not a validated trade signal.
24h model P(up)
An uncalibrated estimate from weighted model scores. It is not a reliable real-world probability until enough out-of-sample results accumulate.
Price ranges
The median target and 10–90% range use up to 120 nearest historical analogues (previously 60). Quantiles use linear interpolation and are rounded to 0.1 percentage point to reduce display jitter. Ranges can still shift when volatility or market regime changes.
Experimental model only. Paper trades are simulations, not live orders. Review the ledger, fees, slippage assumptions and sample size before drawing conclusions. Do not treat a directional lean as a trade instruction.
Source: OKX public hourly candles; derivatives may use the main checkpoint snapshot and OKX public endpoints. Scheduled GitHub Actions runs are best-effort. The page refreshes the saved snapshot every 60 seconds; it does not fetch a new market snapshot every minute.
